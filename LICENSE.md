## 🔧 Common Issues and Fixes

**❌ Problem:** Velocity Executor fails to launch on Windows.
> **Solution:** Ensure your Windows is up-to-date. Run the application as an Administrator by right-clicking the executable and selecting 'Run as administrator'. Also, temporarily disable your antivirus to see if it is blocking the program, then add an exception.

**❌ Problem:** A script fails to execute with an error.
> **Solution:** Check the script syntax for errors. Verify that the script is compatible with your version of Velocity Executor. Enable the debug mode in the settings to get more detailed error logs.

**❌ Problem:** The application is running slowly.
> **Solution:** Close any unnecessary background applications to free up system resources. Ensure your system meets the recommended requirements. Try updating to the latest version of the software.

**❌ Problem:** I cannot import a script from Pastebin.
> **Solution:** Double-check the Pastebin URL for accuracy. Ensure the Pastebin link is set to 'Public' or 'Unlisted'. A 'Private' link will not be accessible.

**❌ Problem:** The AutoFarm function is not working as expected.
> **Solution:** Verify that the game or application you are using it with is open and in focus. Ensure you have configured the AutoFarm settings correctly. Check the application's Terms of Service regarding automation.

**❌ Problem:** I get a security warning when trying to install.
> **Solution:** This is often a false positive from your antivirus. Ensure you have downloaded the file from the official source. If you are confident in the source, you can temporarily disable your antivirus to install the application.

**❌ Problem:** My macros are not recording properly.
> **Solution:** Ensure you are in the correct window before starting the recording. Check your macro settings to ensure mouse and keyboard inputs are being captured correctly. Restart the application to clear any temporary state issues.
